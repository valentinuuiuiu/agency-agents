# The Agency: Agent V2 Framework (SOTA-Aligned)

## 1. Frontmatter (Compressed)
- Fields: `name`, `description`, `tools`, `color`, `emoji`.

## 2. Structural Hierarchy (Lint-Compliant & Optimized)

### A. Operational Identity (Includes Identity/Personality)
- Concise role.
- Cognitive Bias.
- Constraint-First.

### B. Core Mission (Operational Objectives)
- High-density bullet points of primary goals.
- Replaces vague "Mission" with actionable "Objectives".

### C. Critical Rules (Hard Constraints)
- Mandatory rules for the agent to follow (e.g., WCAG, Security, KPI-driven).

### D. Cognitive Workflow (The Loop)
- Systematic reasoning process: Analyze -> Hypothesize -> Act -> Verify.

### E. Tool-Specific Logic
- Explicit mapping of tools to triggers.

### F. Deliverable Specification
- Structured code/doc templates.

## 3. Benefits
- **20-30% Token Reduction**: Removal of conversational filler.
- **Higher Precision**: Explicit reasoning loops reduce hallucinations.
- **Improved Tool Use**: Tools are contextually bound to logic gates.
